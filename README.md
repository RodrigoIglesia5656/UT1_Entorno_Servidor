# UT1_Entorno_Servidor

## Crear proyecto Spring Boot en local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/RodrigoIglesia5656/UT1_Entorno_Servidor.git
   cd UT1_Entorno_Servidor
   ```

2. Abre la carpeta en IntelliJ IDEA.

3. Crea el proyecto Spring Boot (Spring Initializr) dentro del repositorio:
   - `File` -> `New` -> `Project...`
   - Selecciona `Spring Initializr`
   - Group: `com.example`
   - Artifact: `ut1-entorno-servidor`

4. En el paso de dependencias añade `Spring Web`.

5. Finaliza el asistente y espera a que IntelliJ descargue dependencias.
